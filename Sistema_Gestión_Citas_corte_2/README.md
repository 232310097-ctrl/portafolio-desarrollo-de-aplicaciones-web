Proyecto: Sistema de Gestión de Citas
1. Nombre del proyecto

Sistema de Gestión de Citas

2. Objetivo del proyecto

Desarrollar una aplicación web que permita a los usuarios registrarse, iniciar sesión y administrar sus citas mediante operaciones CRUD, utilizando PHP y MySQL.

3. Problema que resuelve

Permite organizar y gestionar citas de manera eficiente, evitando la pérdida de información y facilitando el control de citas futuras e históricas mediante una plataforma web segura.

4. Tecnologías utilizadas
PHP
MySQL
HTML
CSS
XAMPP
Visual Studio Code
5. Conceptos aplicados
Programación web dinámica
Autenticación de usuarios
Manejo de sesiones
Operaciones CRUD
Bases de datos relacionales
Consultas preparadas
Seguridad informática
Validación de datos
Formularios web
Relación entre tablas mediante claves foráneas

6. Instrucciones de ejecución
Instalar XAMPP.
Iniciar los servicios Apache y MySQL.
Crear la base de datos llamada "sistema_citas".
Crear las tablas usuarios y citas.
Copiar el proyecto dentro de la carpeta htdocs.
Abrir el navegador y acceder a la URL del proyecto.
Registrar un usuario nuevo.
Iniciar sesión.
Crear, consultar, editar y eliminar citas.
7. Reflexión personal
¿Qué aprendí?

Aprendí a desarrollar una aplicación web completa utilizando PHP y MySQL, implementando autenticación de usuarios, manejo de sesiones y operaciones CRUD para la gestión de información.

¿Qué fue difícil?

Uno de los principales retos fue la conexión entre la aplicación y la base de datos, así como la implementación de sesiones y medidas de seguridad para proteger la información de los usuarios.

¿Qué mejoraría?

Mejoraría el diseño visual de la interfaz, agregaría recordatorios automáticos de citas, implementaría roles de usuario y reforzaría aún más la seguridad del sistema.
