Proyecto: Portafolio Web Personal en WordPress

1. Nombre del proyecto

Portafolio Web Personal en WordPress

2. Objetivo del proyecto

Desarrollar un sitio web personal utilizando WordPress para presentar información profesional, habilidades, servicios, proyectos realizados y medios de contacto en una plataforma moderna y accesible.

3. Problema que resuelve

Permite centralizar la información académica y profesional en un solo sitio web, facilitando la presentación de proyectos, conocimientos y servicios a posibles empleadores, clientes o colaboradores.

4. Tecnologías utilizadas

* WordPress
* PHP
* HTML
* CSS
* MySQL
* XAMPP
* Visual Studio Code
* Tema Astra

5. Conceptos aplicados

* Gestión de contenidos mediante WordPress
* Diseño y personalización de páginas web
* Organización de información digital
* Administración de sitios web
* Diseño responsivo
* Integración de imágenes y contenido multimedia
* Creación de formularios de contacto
* Publicación de proyectos web
* Uso de temas y herramientas de WordPress

6. Instrucciones de ejecución

1. Instalar XAMPP.
2. Iniciar Apache y MySQL.
3. Crear una base de datos para WordPress.
4. Instalar WordPress en el servidor local.
5. Configurar la conexión con la base de datos.
6. Instalar y personalizar el tema Astra.
7. Crear las páginas Inicio, Sobre mí, Portafolio, Servicios y Contacto.
8. Publicar el sitio y verificar su funcionamiento.

7. Reflexión personal

¿Qué aprendí?

Aprendí a utilizar WordPress para desarrollar un sitio web profesional, personalizando páginas, organizando contenido y mostrando proyectos de manera estructurada. También reforcé conocimientos sobre diseño web y administración de sitios.

¿Qué fue difícil?

La personalización del diseño, la organización del contenido y la configuración de algunos elementos visuales requirieron tiempo y varias pruebas para obtener el resultado esperado.

¿Qué mejoraría?

Mejoraría la apariencia visual del sitio, agregaría más proyectos, incorporaría animaciones e integraría redes sociales y herramientas adicionales para ofrecer una experiencia más completa a los visitantes.
