Proyecto: Sistema de Agenda Web

1. Nombre del proyecto

Sistema de Agenda Web

2. Objetivo del proyecto

Desarrollar una aplicación web que permita registrar usuarios, contactos y citas mediante formularios conectados a una base de datos MySQL.

3. Problema que resuelve

Facilita la administración de información personal y profesional al permitir almacenar contactos y programar citas de manera organizada en una base de datos.

4. Tecnologías utilizadas

* HTML
* PHP
* JavaScript
* MySQL
* Visual Studio Code
* XAMPP

5. Conceptos aplicados

* Formularios web
* Validación de datos con JavaScript
* Programación del lado del servidor con PHP
* Conexión a bases de datos con MySQL
* Sentencias SQL (INSERT)
* Organización de archivos web
* Seguridad básica mediante hash de contraseñas



6. Instrucciones de ejecución

1. Instalar XAMPP.
2. Iniciar Apache y MySQL.
3. Crear la base de datos "agenda_web".
4. Crear las tablas usuarios, contactos y citas.
5. Copiar el proyecto dentro de la carpeta htdocs.
6. Abrir el navegador y acceder a:
   http://localhost/nombre_del_proyecto
7. Registrar usuarios, contactos y citas mediante los formularios.

7. Reflexión personal

¿Qué aprendí?

Aprendí a desarrollar aplicaciones web dinámicas utilizando HTML, PHP y MySQL, así como a conectar formularios con una base de datos para almacenar información.

¿Qué fue difícil?

La configuración de la conexión con la base de datos, la validación de formularios y la organización de los archivos del proyecto fueron los aspectos más complejos durante el desarrollo.

¿Qué mejoraría?

Mejoraría la interfaz gráfica, implementaría validaciones más avanzadas, utilizaría consultas preparadas para aumentar la seguridad y agregaría funciones para editar y eliminar registros.
