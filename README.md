Descripción General

El presente portafolio reúne los proyectos desarrollados a lo largo del semestre en la materia de Desarrollo de Aplicaciones Web. Cada proyecto incluye su respectiva documentación con el propósito de presentar de manera clara los objetivos, tecnologías utilizadas, procedimientos realizados y resultados obtenidos durante su desarrollo.

Para la elaboración de los proyectos se utilizaron diversas tecnologías y herramientas, entre las que destacan PHP, HTML, Visual Studio Code, bases de datos MySQL, Moodle y WordPress. Estas herramientas permitieron desarrollar aplicaciones web funcionales y adquirir experiencia práctica en el diseño e implementación de soluciones informáticas.

Durante el desarrollo de los proyectos se fortalecieron diversas competencias relacionadas con la programación web, el manejo de PHP y HTML, la gestión de bases de datos, la resolución de problemas, el pensamiento lógico, la documentación técnica, la organización de proyectos y el trabajo autónomo. Asimismo, se desarrollaron habilidades en el uso de plataformas como Moodle y WordPress, fundamentales para el ámbito profesional del desarrollo de software y aplicaciones web.

Proyectos Incluidos
1. Actividad de Evaluación Basada en Proyecto — Corte 1

Proyecto enfocado en la aplicación de los conocimientos adquiridos durante la primera etapa del curso, utilizando tecnologías web para desarrollar una solución funcional y documentada.

2. Proyecto de Evaluación DAW-2.1: Desarrollo de un Sistema de Citas

Sistema web desarrollado con PHP y MySQL que permite el registro e inicio de sesión de usuarios, así como la administración de citas mediante operaciones CRUD (Crear, Consultar, Actualizar y Eliminar).

3. Proyecto de Evaluación C3: Portafolio en WordPress

Desarrollo de un sitio web utilizando WordPress como gestor de contenidos, aplicando conceptos de diseño web, organización de información y personalización de temas y recursos digitales.

Conclusión

Los proyectos incluidos en este portafolio representan la aplicación práctica de los conocimientos adquiridos durante el semestre. Gracias a su desarrollo fue posible fortalecer competencias técnicas y profesionales relacionadas con la programación web, el uso de bases de datos y la creación de aplicaciones funcionales, consolidando así una base sólida para futuros proyectos en el área del desarrollo de software.
